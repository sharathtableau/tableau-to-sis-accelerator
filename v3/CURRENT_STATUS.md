## Known limits and risks

- Visual fidelity is improved but not universally pixel-perfect. Tableau uses layout, font, label-placement, and collision behavior that must be mapped by feature class rather than patched per workbook.
- Unsupported or only partially supported Tableau features remain in `audit_coverage.py` and the roadmap; do not present the accelerator as covering every Tableau construct.
- Nested dashboard-sheet Tableau data export remains constrained by Tableau API/site behavior for some validation paths.
- The worktree has concurrent/uncommitted changes from more than one coding assistant. Inspect `git status` and diffs before every edit; never reset or replace another session's work.
- Local environment variables are not automatically available inside Streamlit-in-Snowflake. Production authentication depends on the bound Snowflake Secret and External Access Integration.
